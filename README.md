# Movilidad sostenible en Cali

Presentación web interactiva sobre los avances, obstáculos y potencial de la movilidad sostenible en Santiago de Cali.

Tema 5 · Cambio climático: mitigación y adaptación — Ambiente y desarrollo sostenible, Universidad Autónoma de Occidente.

**Integrantes:** Miguel Diaz · Manuel Villamarin · Jose Giraldo · Santiago Camayo
